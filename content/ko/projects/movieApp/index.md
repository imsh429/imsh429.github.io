<p style="text-align:justify;">
<b>Netflix Demo</b>는 TMDB API를 활용하여 실제 스트리밍 서비스와 유사한 사용자 경험을 제공하는 <b>영화 큐레이션 웹 애플리케이션</b>입니다. Vue 3의 Composition API와 TypeScript를 기반으로 설계되었으며, 단순히 데이터를 나열하는 것을 넘어 사용자 맞춤형 찜하기 기능, 다이나믹 뷰 모드(Table/Scroll), 그리고 고도화된 CSS 애니메이션을 통해 완성도 높은 UI/UX를 구현했습니다. 특히 로컬 스토리지를 활용한 개인화된 데이터 관리와 9개 이상의 미디어 쿼리를 통한 완벽한 반응형 디자인으로 어떤 환경에서도 최적화된 시청 탐색 경험을 제공합니다.
</p>

## 🎬 프로젝트 소개

이 프로젝트는 최신 영화 트렌드를 한눈에 파악하고 관리할 수 있는 SPA(Single Page Application)입니다. **TMDB(The Movie Database) API**를 통해 실시간 데이터를 동기화하며, 사용자가 직접 입력한 API 키와 이메일을 활용한 로컬 인증 시스템을 갖추고 있습니다. 7가지 이상의 인터랙티브 애니메이션을 통해 웹 UI의 역동성을 극대화한 것이 특징입니다.

### 주요 기능 (Core Features)

* **다차원 영화 큐레이션**: 인기 영화, 현재 상영작, 최고 평점, 개봉 예정작 등 4가지 카테고리의 실시간 데이터 제공
* **사용자 인증 및 데이터 격리**: 이메일 기반 로그인 및 localStorage를 활용한 사용자별 찜 목록(Wishlist) 분리 저장
* **듀얼 뷰 모드 (Popular)**: 페이지네이션 기반의 **Table View**와 끊김 없는 콘텐츠 탐색을 위한 **무한 스크롤(Infinite Scroll)** 모드 토글 지원
* **지능형 검색 시스템**: 실시간 쿼리 기반의 영화 검색 및 검색 결과 내 페이지네이션 처리
* **찜하기 및 통계**: 관심 영화 저장 기능과 더불어 7가지 정렬 옵션, 찜한 목록의 평균 평점 등 통계 대시보드 제공

## ✨ 기술적 핵심 포인트

### 1. 인터랙티브 UX (Animation & Transition)
사용자 몰입감을 높이기 위해 **7가지 이상의 전용 애니메이션**을 적용했습니다.
* **MovieCard Hover**: 포스터 확대 및 입체적인 그림자 효과
* **Hero Section**: 초기 로딩 시 부드러운 Fade-in 연동
* **Route Transition**: 페이지 이동 시 자연스러운 전환 효과 적용

### 2. 고도화된 반응형 레이아웃
9개 이상의 미디어 쿼리를 활용하여 디바이스별 최적화된 그리드를 제공합니다.
* **모바일 (≤480px)**: 1열 배치 및 햄버거 메뉴 전환
* **태블릿 (≤1024px)**: 2~3열 배치 및 축소 네비게이션
* **데스크톱 (>1024px)**: 최대 6열 배치 및 전체 메뉴 노출

## 🚀 개발 회고

* **컴포저블(Composables) 패턴의 활용**: `useMovies`, `useAuth` 등 비즈니스 로직을 독립적인 함수로 분리하여 코드 재사용성과 가독성을 높였습니다.
* **API 통합 역량**: 외부 API의 복잡한 데이터를 수신하여 UI 요구사항에 맞게 가공하고, 검색 결과 없음 등 예외 상황을 처리하는 능력을 배양했습니다.
* **성능 최적화**: 무한 스크롤 구현 시 효율적인 이벤트 리스닝과 데이터 로딩 시점 조절을 통해 렌더링 성능을 개선했습니다.

고금리 장기화에 따른 대출 연체율 급증 문제에 대응하기 위해 기획된 <b>AI 기반 리스크 관리 솔루션</b>입니다. 팀장으로서 금융 현장의 Pain Point를 분석하여 서비스 모델을 수립하고, <b>AWS 서버리스 아키텍처와 자동화된 배포 파이프라인</b>을 통해 데이터 분석부터 모니터링까지 전 과정을 아우르는 플랫폼을 구축했습니다.

## 💡 프로젝트 소개

이 프로젝트는 기존 금융권의 수동적인 대출 심사 및 사후 관리 체계의 한계를 극복하기 위해 시작되었습니다. 단순 통계 수치를 넘어 **NLP(자연어 처리)와 머신러닝**을 결합하여 차주의 상환 능력을 다각도로 예측하고, 이를 대시보드로 실시간 시각화하여 금융 사고를 미연에 방지하는 것을 목표로 합니다.

## 💡 프로젝트 팀장 & 기획자로서의 역할

단순히 개발을 리딩하는 것을 넘어, 금융 현장의 문제를 기술로 해결하는 **전 과정의 아키텍트 역할**을 수행했습니다.

* **비즈니스 모델 수립**: 고금리 상황 속 은행 연체율 관리의 어려움을 파악, 수동 심사를 대체할 'AI 기반 선제적 리스크 모니터링' 서비스 기획
* **개발 프로세스 표준화**: 요구사항 명세서 작성부터 Sequence Diagram 설계, GitHub Organization 관리 및 기술 문서화를 주도하여 팀의 개발 생산성 극대화
* **리스크 지표 설계**: 7개의 핵심 데이터 테이블을 기반으로 상환 능력 예측에 유의미한 200여 개의 파생 변수(Feature) 선별 및 모델링 전략 수립

## 🛠 주요 성과 및 기술적 도전

## 🏗️ 하이브리드 클라우드 인프라 아키텍처 (Infra & DevOps)

시스템의 가용성을 높이기 위해 **서비스 특성에 따른 리소스 분리 전략**을 수립하고 인프라를 직접 구축했습니다.

### 1. 부하 격리를 통한 서비스 안정성 확보
* **Web/API Zone (EC2)**: 실시간 대시보드와 사용자 인증이 이루어지는 Spring Boot 서버는 EC2에 배치하여 상시 가용성을 보장했습니다.
* **AI Prediction Zone (Serverless ECS Fargate)**: 대규모 컴퓨팅 파워가 필요한 ML 모델 실행 시 웹 서버의 자원을 잠식하지 않도록 **Fargate 기반 컨테이너 환경**으로 격리 구축했습니다. 

### 2. 비용 최적화 및 스케줄링 자동화
* **EventBridge 배치 설계**: 무거운 AI 모델을 24시간 가동하는 대신, 정해진 시간마다 예측을 수행하도록 **EventBridge** 스케줄러와 연동하여 불필요한 클라우드 비용을 최소화했습니다.
* **ECR 기반 이미지 관리**: 모델 업데이트 및 배포의 유연성을 위해 Docker 컨테이너화를 수행하고 ECR을 통해 통합 관리했습니다.

### 3. CI/CD 파이프라인 및 보안
* **GitHub Actions 자동화**: 소스 코드 검증부터 AWS 배포까지 전 과정을 자동화하여 휴먼 에러를 방지했습니다.
* **Redis 인증 시스템**: 이메일 인증 등 휘발성 데이터를 위해 Redis를 도입하여 DB 부하를 분산하고 인증 응답 속도를 개선했습니다.

## 🛠 기술 스택

| 분류 | 기술 스택 | 상세 역할 |
| :--- | :--- | :--- |
| **Cloud Infra** | **AWS (EC2, ECS Fargate, ECR, S3)** | 서비스 특성별 리소스 격리 및 하이브리드 아키텍처 설계 |
| **DevOps** | **GitHub Actions, Docker, EventBridge** | 무중단 배포 환경 구축 및 배치 스케줄링 자동화 |
| **Data/DB** | **MySQL(RDS), Redis, Python** | 200여 개 파생변수 적재를 위한 ERD 설계 및 데이터 가공 |
| **Backend** | **SpringBoot, Java** | JWT/Redis 기반 인증 시스템 및 모니터링 API 개발 |
| **Management** | **Notion, GitFlow** | 프로젝트 일정 관리, 요구사항 정의 및 기술 문서화 주도 |

## 🚀 성과 및 회고

* **아키텍처 설계 역량**: 서비스 안정성과 비용 절감이라는 두 마리 토끼를 잡기 위해 **EC2와 Fargate를 조합한 하이브리드 아키텍처**를 제안하고 실현하며 클라우드 인프라 엔지니어링 역량을 증명했습니다.
* **팀장으로서의 조율 능력**: AI 파트와 웹 파트 간의 데이터 통신 규격을 정립하고, 철저한 설계를 바탕으로 협업을 이끌어 마감 기한 내에 고도화된 완성도를 달성했습니다.
* **데이터 인사이트**: 금융 데이터를 이해하는 엔지니어로서, 효율적인 DB 정규화와 대규모 변수 처리를 경험하며 IT 전문가로서의 기반을 다졌습니다.

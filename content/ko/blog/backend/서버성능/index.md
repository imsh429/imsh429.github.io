# 성능 : ‘처리량/응답 시간’ 지표 활용

- 성능 개선을 위해선 현재 서버의 TPS와 응답 시간을 알아야 한다.
- 트래픽 많은 시간대 TPS/응답시간 측정 → 목표 TPS와 응답시간 설정 ⇒ 성능 개선안 도출

TPS 모니터링 도구 :  스카우터, 핀포인트, 뉴델릭

## 1. 응답 시간 (response time)

- 사용자의 요청을 처리하는 데 걸리는 시간
- API 요청 (서버 연결→서버로 데이터 전송) → SQL 실행. 응답 생성 (서버 실행) → API 응답 (클라이언트로 데이터 전송)
- TTFB (Time To First Byte) / TTLB (Time To Last Byte) 중 적절한 지표 선택해 서버 성능 측정
- 응답 시간 : ms 단위 사용
- 응답 시간 : API 요청 전송 시간 + 서버 처리 시간 + API 응답 전송 시간
- 서버 처리 시간 : DB 연동(SQL 실행) / 외부 API 연동

## 2.  처리량 (TPS/RPS)

- 단위 시간 당 시스템이 처리하는 작업량
- TPS (Transaction Per Second) : 초당 트랜잭션 수
- RPS (Request Per Second) : 초당 요청 수
- 최대 TPS : 시스템이 처리할 수 있는 최대 요청 수
- 최대 TPS 초과하는 요청 ⇒ 응답 시간 지연 ⇒ 사용자 이탈
- TPS 높이는 방법

1) 서버가 동시에 처리할 수 있는 요청 수 늘려 대기 시간 줄이기

2)처리 시간을 단축해 대기 시간 줄이기
